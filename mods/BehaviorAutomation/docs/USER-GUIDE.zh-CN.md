# 行为学

| 操作 | 功能 |
| --- | --- |
| 按住 Shift + 左键拖动 | 按左键基础处理手持道具，并加入左键全局行为 |
| 按住 Shift + 右键拖动 | 从允许的行为中自动选择工具并处理选区 |
| F8 | 打开 / 关闭行为与设置面板 |
| 拖框到屏幕边缘 | 移动视角，继续扩大当前地图内的选区 |
| 再次按 Shift | 取消任务 |
| 连续移动 0.5 秒 / 打开背包 | 取消任务 |

新框选总是替换旧选区。空选区立即结束。短暂移动时让玩家先走，松开后继续工作。头顶动态图标表示当前任务，工作区域不留常驻标记。

## 行为面板

| 页面 | 作用 |
| --- | --- |
| 左键基础（第一项） | 手持相应工具、种子或材料时，左键框选允许执行的行为 |
| 左键全局 | 不限手持道具，左键框选额外加入的行为 |
| 右键工具池 | 右键框选允许智能选择的行为 |
| 设置 | 样式、快捷键、选框尺寸、移镜、建筑内作业、仓库工具和植树间距 |

前三页行为集合相互独立，无总开关或父子关系。例如：基础允许伐木、全局关闭伐木，只有手持斧头左键框选才会砍树。全局允许挤奶时，即使手持食物，也能借用可用的挤奶桶完成挤奶。

左键全局默认包含采集与动物日常照料。锄地、种植和放置只出现在左键基础页，需要手持对应道具。

绿色高亮表示选中，暗色表示关闭。三个行为页都有全选、清空，作用于整页。点击即保存，Tab 切页，滚轮翻动。

## 铺设与放置

拿着地板、路径、围栏、火把、洒水器、箱子或机器，按住 Shift 左键框选。

- 按行规划位置，从可达的近处开始，数量不超过背包内同类材料的实际总数。
- 跳过已铺地板、已有物品、作物与不能放置的位置，不替换已有内容。
- 走到位置后调用原版放置，成功才消耗材料；取消后停止。
- 不从箱子或其他物品中推断建筑材料。炸弹、楼梯、家具和整屋壁纸不作为区域填充物品。

## 拆除地板

手持斧头或镐子，按住 Shift 左键框选地板或路径。F8 → 左键基础 → 拆除地板，可独立关闭。原版掉落材料保持不变；已有物品、家具或建筑覆盖的位置会跳过。左键全局和右键工具池不包含此项。

## 自动作业

- 按真实目标选择站位并进行八方向寻路，镰刀结合剩余目标分布成片收获，只处理成熟作物。
- 浇水根据水壶等级和延伸附魔选择蓄力范围；缺水时在当前地图寻找可达池边、水井等位置，补满后继续。只浇选中且允许的目标。
- 空手交互包含成熟作物、采集物、机器成品等。动物照料包含抚摸、挤奶、剪毛、添干草、宠物与水碗；改名、出售、迁移和金色动物饼干仍手动操作。
- 种植需要手持种子或树苗，树干间距默认普通树 2 格、果树 3 格（中间分别空 1 格、2 格），可独立调大，并遵守游戏生长条件。
- 先绕过障碍；无路时只尝试清理当前行为集合允许且可安全移除的路障，不拆箱子、建筑、围栏或活作物。
- 单人游戏可借用各地图箱子里的原工具，使用后归还。联机仅使用背包工具。
- 左键基础任务及其清障使用选定的那把工具。左键全局、右键智能任务可按配置换用实际持有或仓库中可借用的工具，不提升工具等级。
- 遵守原版限制：大树桩需铜斧、大原木需钢斧、农场巨石需钢镐、陨石需金镐。矿井普通大石块、普通树木残桩不套用这些升级要求；附魔效果按原版计算。
- 选区完成前持续检查后续任务，例如抚摸后出现的产物；完成后停止检查。

## 样式与快捷键

配置页默认侧栏图标，选框默认网格；F8 设置页可切换三种配置页样式和三种选框样式，并修改框选、面板、取消三个快捷键。

点击键位，按新按键或组合键并松开即可保存；Esc 取消本次录入，“重置”恢复该项默认键位。单次录入替换该项绑定；已有多组备选键会保留，直到主动修改。设置页可用滚轮或底部箭头翻动。

## 模组配置

Generic Mod Config Menu 中提供 22 项设置。F8 的前三页选择行为，第四页直接调整样式、三个快捷键、选框尺寸、移镜、建筑作业、仓库工具和植树间距，无需其他配置模组。

| 设置 | 默认值 / 范围 |
| --- | --- |
| 启用、三个快捷键、仓库工具、保留体力 | 保留原设置 |
| 移动取消时间 | 0.5 秒，可调 0.1–2 秒 |
| 允许斜向寻路 | 开启；不会穿过阻挡的墙角 |
| 镰刀额外走位 | 12 格，可调 2–24 格 |
| 镰刀聚拢程度 | 16，可调 4–32；越高越愿意多走几格减少挥刀 |
| 水壶自动补水 | 开启 |
| 允许清理挡路物 | 开启；仍受行为集合和安全条件限制 |
| 配置页样式 | B · 侧栏图标；可选木框卡片、侧栏图标、紧凑列表 |
| 选框样式 | C · 网格；可选淡填充、纯边框、网格 |
| 显示选框尺寸 | 开启；拖框时显示宽 × 高格数，松开后隐藏 |
| 拖框时边缘移镜 | 开启；松开后视角回到角色 |
| 移镜速度 | 12 格/秒，可调 4–24 |
| 处理选中建筑内部 | 开启；复用本次框选的行为集合 |
| 普通树树干间距 | 2 格，可调 2–8 |
| 果树树干间距 | 3 格，可调 3–8 |
| 目标复查间隔 | 0.3 秒，可调 0.1–1 秒 |
| 完成前复查时间 | 1.5 秒，可调 0.3–3 秒 |

再生作物收获后进入冷却时立即跳过，等再次成熟后才能纳入新选区。金镰刀和 Harvest With Scythe 同用时，地面采集收尾不会再触发额外挥刀。升级保留已有快捷键和三套行为集合。

需要 Stardew Valley 1.6.15 与 SMAPI 4.5.2；推荐安装 Generic Mod Config Menu。将成品中的 `BehaviorAutomation` 文件夹放入游戏 `Mods`。

2.1 升级时保留原本实际启用的行为、快捷键和通用配置；之后三页独立修改。旧版本的附近任务、暂停键和多套标记模式已移除。


## 跨镜头与建筑

拖框接近屏幕边缘时视角随之移动，角色留在原地；松开鼠标后开始工作，视角恢复跟随。选区以方格为单位，限当前地图，最大 64×64 格。尺寸标签按实际选区计算，包括起止格；反向拖动也按宽 × 高显示，靠近屏幕边缘时自动避让。F8 → 设置 → 显示选框尺寸，可关闭。

选框与已建成建筑的占地相交，且内部存在当前行为集合允许的任务时，会将入口加入队列。角色从正常入口进入，完成动物照料、收货等室内工作后，沿出口返回并继续外部选区。建筑每个选区访问一次；关闭“处理选中建筑内部”即可只做屋外任务。

普通工作按可达路径就近处理；镰刀和水壶兼顾一轮覆盖数量。种植与铺设保留整齐的位置规划，执行顺序从角色附近开始。

## 开发方向

后续开发将以选框内自动化为主干，优先完善现有操作、寻路与兼容性。为控制模组体量和维护成本，尽量减少额外智能处理和职责外的子功能。
